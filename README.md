# Dividend Tracker Android

Modern Android dividend and investment portfolio tracker built with Kotlin and Jetpack Compose.

## Features

- Portfolio dashboard
- Dividend income tracking
- Passive income goals
- Investment holdings management
- Dividend calendar
- Bottom navigation architecture
- Modern Material 3 UI

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Gradle Kotlin DSL

## Architecture

The project follows a clean package structure:

```text
data/
domain/
presentation/
navigation/
ui/
```
